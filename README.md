Superstore Sales Analysis (Python)
Project Overview

This project focuses on analyzing retail sales data using Python to uncover key business insights. The analysis includes revenue trends, customer behavior, and product performance.

Objectives
Understand sales performance across products, categories, and cities
Identify top-performing products and customers
Analyze customer behavior (Repeat vs One-time)
Calculate key business metrics like Average Order Value (AOV)
Visualize insights using charts

Tools & Technologies
Python
Pandas
Matplotlib
Seaborn
Jupyter Notebook

Dataset

The dataset contains:

Order details (order_id, order_date)
Customer information (customer_id, city)
Product details (product, category)
Sales data (quantity, price, revenue)

Key Analysis
🔹 Basic Metrics
Total Revenue
Total Orders
Unique Customers
🔹 Core Analysis
Top 5 Products by Revenue
Revenue by Category
Revenue by City
🔹 Intermediate Analysis
Top Customers by Spending
Monthly Revenue Trend
Highest Performing Category
🔹 Advanced Analysis
Average Order Value (AOV)
City-wise AOV
Repeat vs One-time Customers

🔹 Business Insights
Repeat customers contribute a significant portion of total revenue
Certain products dominate overall sales performance
Revenue varies significantly across cities
High-value customers drive a large share of revenue

Conclusion
This project demonstrates how Python can be used to transform raw data into meaningful business insights, helping stakeholders make data-driven decisions.
